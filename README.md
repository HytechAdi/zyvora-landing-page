# ZYVORA

**Where Ideas Become Extraordinary**

ZYVORA is a landing page designed for a creative digital studio. The main goal of this project is to create a clean, modern website that looks good on both desktop and mobile devices.

The website uses a dark theme with purple gradients, simple animations, and an easy-to-use layout.

## Features

* Modern dark-themed design
* Responsive layout for different screen sizes
* Navigation menu for easy browsing
* Animated elements and smooth scrolling
* Service cards with hover effects
* About and contact sections
* Mobile-friendly navigation
* Footer with an automatically updated year

## Technologies Used

* HTML5 for the website structure
* CSS3 for styling, animations, and responsive design
* JavaScript for interactive features
* Google Fonts for typography

## Project Structure

```text
Zyvora/
```

## How to Run

1. Download the project files or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. The website will open in your browser.

An internet connection is needed to load Google Fonts.

## Customization

You can change the text, colors, fonts, and other design elements by editing the HTML and CSS files.

Before publishing the website, replace the sample contact email with your own email address.

## What I Learned

While working on this project, I practised creating responsive layouts, styling elements with CSS, adding animations, and using JavaScript to handle basic interactions.
